# assets

Coloque aqui a logo da Pulsar.

- Nome do arquivo: `logo.png` (de preferencia PNG com fundo transparente).
- O `index.html` aponta para `assets/logo.png` no topo da sidebar.
- Enquanto o arquivo nao existir, o app mostra um fallback (asterisco em SVG + wordmark
  "Pulsar"). Assim que voce salvar `logo.png` aqui, a imagem aparece automaticamente.

Para trocar por outro nome ou formato, ajuste o `src` do `<img class="brand-logo">`
no `index.html`.
